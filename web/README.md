# 3.75 Collection – desktop web app

Open index.html through a static HTTP server or GitHub Pages.
The full 1,257-item catalog is included. Data is saved locally in your browser.
Back up collection data using the built-in JSON export.
Phone and PC can exchange backups or use the optional local sync server.

Desktop shortcuts: Ctrl+K search, Ctrl+Shift+S backup, Ctrl+Shift+D dashboard.
